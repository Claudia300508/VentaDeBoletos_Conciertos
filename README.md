## 📖 Sobre el proyecto

**UCA Tickets** es un proyecto de la universidad que simula una plataforma de venta de boletos para conciertos. Está pensada para tres tipos de personas:

- **Clientes**, que compran boletos y consultan sus entradas.
- **Organizadores**, que publican sus eventos.
- **Administradores**, que gestionan la plataforma.
